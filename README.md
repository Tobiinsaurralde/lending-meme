Frontend con la misma interfaz que [ContextLock](https://context-lock-frontend.vercel.app/), copiada desde [`apps/frontend`](https://github.com/austinjeremiah/ContextLock/tree/main/apps/frontend).

## Desarrollo

```bash
npm install
cp .env.example .env.local
npm run dev
```

La app queda en http://localhost:3000.
